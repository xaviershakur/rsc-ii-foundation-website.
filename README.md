# RSC II Foundation website starter

A responsive, single-page website starter for the RSC II Foundation, using the gold, cream, and black visual direction from the provided reference images.

## Preview locally
Open `index.html` in a browser. The page uses `styles.css` and has no build step.

## Before publishing
1. Replace `YOUR-EMAIL-HERE` in `index.html` with the foundation's official contact email.
2. Add official social links, event photos, and verified impact numbers if desired.
3. Confirm the organization's approved wording and any nonprofit/tax-status claims before publishing.
4. If you want to accept donations, connect a trusted donation provider; this starter does not process payments.

## Publish with GitHub Pages
1. On GitHub, create a new repository (for example, `rsc-ii-foundation-website`).
2. Upload `index.html`, `styles.css`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then Save.
6. GitHub will show the published website URL in the Pages section.

The design uses Google Fonts when online and falls back to system fonts if unavailable.
